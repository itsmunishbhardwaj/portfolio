The Solution

Test infrastructure is CI/CD infrastructure

  • A custom pytest plugin (hac-playwright) — abstracts away Keycloak, Okta, and OTP auth so tests don't break every time an identity provider changes. Auth becomes one solved problem, not three recurring ones.
  • 198 Playwright specs covering every application and every data connector (S3, Redshift, BigQuery, Azure Blob, Snowflake, HDFS, Databricks, Delta Table). Breadth, not just depth.
  • 10 GitHub Actions workflows — a main test runner, dedicated UI workflow, release-testing with dynamic environment matrices, connector-suite testing, and a two-phase generate/validate workflow for upgrade testing. CI/CD design, not just test-writing.
  • A 1,003-line root conftest.py with parallel-test isolation (xdist_group) and resource tracking for pre/post-upgrade validation. Infrastructure other engineers build tests on top of.
Auth changes should never be why a test suite breaks.

Key Learnings
1

Test infrastructure is CI/CD infrastructure, not "just QA."

The auth-provider plugin, the workflow matrix design, and the parallel-isolation fixtures are pipeline engineering — they happen to gate tests, but the skill is the same as gating deployments.

2

Abstraction pays for itself the second time a dependency changes.

Building hac-playwright once meant the next Okta or Keycloak change didn't break every UI test — it broke one plugin.

3

A suite that only reports green isn't trustworthy.

The May 26 RC2 run had real failures and errors reported alongside passes — that's a signal worth showing, not hiding.
