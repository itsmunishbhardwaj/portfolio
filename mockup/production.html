The test report that cites its sources

A reusable GitHub Actions workflow. It reads the JUnit results, hands structured test data to H2OGPTE, and renders a standalone report: pass, conditional pass or fail, with a root cause for each failure.

Every claim the model makes is threaded back to the CI run, the source file and the test name. When the model is unavailable, the report still ships, with data only.
